### Source 1: Value Investing: The Use of Historical Financial Statement Information to Separate Winners from Losers (Piotroski, Univ. of Chicago GSB, Jan 2002 Selected Paper No.84; original JAR 2000) — https://www.anderson.ucla.edu/documents/areas/prg/asam/2019/F-Score.pdf
- **Status**: retrieved (full 42-page text). OCR of some symbols garbled; flagged inline.
- **Formulae — the nine binary signals, in three groups.** Indicator = 1 if the signal realization is "good", 0 if "bad". All accounting values are for fiscal year t ("the year preceding portfolio formation"); denominators use *beginning-of-year* total assets unless stated.

  **Profitability (4):**
  1. **F_ROA** — level/sign test: 1 if ROA_t > 0 else 0. `ROA = (net income before extraordinary items) / (total assets at beginning of year t)`.
  2. **F_CFO** — level/sign test: 1 if CFO_t > 0 else 0. `CFO = (cash flow from operations) / (total assets at beginning of year t)`.
  3. **F_ΔROA** — YoY delta/sign test: 1 if ΔROA > 0 else 0, where `ΔROA = ROA_t − ROA_{t−1}` (ROA as above, each on its own beginning assets).
  4. **F_ACCRUAL** — level/relative test: 1 if CFO > ROA else 0 (i.e. accruals negative). `ACCRUAL = (NI before extraordinary items − CFO) / (total assets at beginning of year t)`. Paper text (OCR): "F_ACCRUAL equals one if CFO [>] ROA".

  **Leverage, Liquidity & Source of Funds (3):**
  5. **F_ΔLEVER** — YoY delta/sign test: 1 if the leverage ratio *fell* in the year preceding formation else 0. `LEVER = Δ( total long-term debt (including the current portion) / average total assets ) between end of year t and t−1`.
  6. **F_ΔLIQUID** — YoY delta/sign test: 1 if liquidity improved (current ratio rose) else 0. `LIQUID = Δ( current assets / current liabilities ) between fiscal year-end t and t−1`.
  7. **F_EQ_OFFER** — event test: 1 if the firm did **not** issue common equity in the year preceding formation, 0 if it did.

  **Operating Efficiency (2):**
  8. **F_ΔMARGIN** — YoY delta/sign test: 1 if ΔMARGIN > 0 else 0. `MARGIN = gross-margin-ratio_t − gross-margin-ratio_{t−1}`, where `gross margin ratio = (net sales − COGS) / net sales`.
  9. **F_ΔTURN** — YoY delta/sign test: 1 if ΔTURN > 0 else 0. `TURN = asset-turnover_t − asset-turnover_{t−1}`, where text defines `asset turnover = net sales / beginning-of-year total assets`; the Table-1 variable list instead says "net sales scaled by **average** total assets for the year" (discrepancy noted in the source — the paper uses both words).

- **Summation & bands:** `F_SCORE = F_ROA + F_ΔROA + F_CFO + F_ACCRUAL + F_ΔMARGIN + F_ΔTURN + F_LEVER + F_LIQUID + F_EQ_OFFER`, integer 0–9. **Low F_SCORE = 0 or 1** (n=396); **High F_SCORE = 8 or 9** (n=1,448). Alternative low band (F_SCORE ≤ 2, n=1,255) gives qualitatively similar results. Robustness: annually ranking each signal 0–1 and summing (RANK_SCORE) yields a significant high-low quintile spread (mean 0.092, median 0.113, 1% level).
- **Accounting conventions:** (i) profitability uses *net income before extraordinary items* and *cash flow from operations* scaled by *beginning-of-year* total assets; (ii) ROA uses beginning-of-year total assets (not ending/average); (iii) benchmarks are **absolute** (ROA>0, CFO>0), chosen because 41.6% of high-BM firms had a loss in the prior two fiscal years and because an absolute benchmark needs no industry/market/time comparison — footnote 3 states "industry-adjusted" factors gave results not substantially different from the main portfolio results; (iv) LEVER/TURN denominators are described as *average* total assets in the variable list. No numeric thresholds beyond the zero/sign tests; every pass threshold is a strict sign/level test.
- **Aggregation / window:** Annual, point-in-time at fiscal year-end; firm-specific returns are 1-yr (2-yr) buy-and-hold from **the beginning of the 5th month after fiscal-year-end** (to ensure annual statements are public) to the earlier of +1yr(+2yr) or last CRSP trading day; delisting return assumed 0. Market-adjusted = BHR − value-weighted market BHR. BM quintiles and size terciles assigned each year using the **prior** fiscal-year distribution (avoids look-ahead).
- **Normalisation / weighting:** **equal unit weights** — each of the nine binary signals contributes exactly 1. No z-scores, percentiles, winsorising, or sector neutralisation. Binary binarisation explicitly avoids year-by-year model fitting (a "step-back" vs Ou-Penman/Holthausen-Larcker). Sensitivity check: continuous annually-ranked signals, and partitioning on Altman Z-score and ΔROA, all confirm the aggregate is not metric-specific.
- **Validation evidence:** COMPUSTAT+CRSP, **highest BM quintile, 14,043 firm-year observations, 1976–1996 (21 years)**; ~75,000 total Compustat obs of which 14,043 high-BM. Size split: 8,302 small (59.12%), 3,906 medium (27.81%), 1,835 large (13.07%).
  - High−Low **one-year market-adjusted**: **0.230** (High 0.134 vs Low −0.096), t=5.590, bootstrap p=0.000. Raw High−Low **0.235** (0.313 vs 0.078).
  - High−All high-BM: **0.075** market-adjusted (0.134 vs 0.059), t=3.140. Raw 0.074.
  - Two-year market-adjusted High−Low: **0.432** (0.287 vs 0.145); High−All 0.160.
  - **Long/short (long 8-9, short 0-1) annual return 1976–1996 = ~23%** (abstract; CFA UK cites 23.5% CAGR).
  - Spearman corr(F_SCORE, 1-yr MA ret) = 0.121; 2-yr = 0.130; strongest singles ROA 0.086, CFO 0.096.
  - Regression (controls log MVE, log BM, momentum, accruals decile, EQ_OFFER): one extra signal ≈ **+2% to +3%** MA return (coefficient 0.031–0.032, t≈6–8).
  - Appendix 1 (long F≥5 / short F<5): avg strong 0.106, weak 0.009, diff **0.097** (t=5.059); positive in **18 of 21 years**, largest negative −0.036 (1989).
  - Future fundamentals: High−Low ΔROA_{t+1}=0.106 (t=15.018); low-F firms **>5× more likely** to performance-delist (High−Low delist prop. −0.083, t=7.878). Earnings-announcement (−1,+1) 4-quarter sum: High 0.049 vs Low 0.008, diff 0.041 (~one-quarter of annual return diff earned in 12 trading days).
  - **Size/BM adjusted?** Main tests are market-adjusted only; size and BM are not neutralised in the portfolio sorts, but a cross-sectional regression controls for log(MVE) and log(BM) and the small size/BM variation across F_SCORE portfolios is argued not to explain the ~22% spread.
- **Stated limitations / failure modes (explicit in paper):**
  - Benefits concentrated in **small and medium firms**; for **largest firms** differentiation is weak/insignificant (large High−All t=0.872, p=0.203; large High−Low t=1.884, p=0.224).
  - In **high share-price** and **high trading-volume** partitions the High−Low diff is significant but High−All is **not**; the large-share-price partition shows an *insignificantly negative* mean/median High−All difference. Suggests benefits partly via eliminating the left tail rather than picking winners.
  - **With analyst coverage** the High−Low diff is 0.114 (t=1.832, only marginal) vs 0.277 without coverage.
  - **Data-snooping bias** acknowledged (signals chosen partly from prior published results → could degrade out-of-sample predictability).
  - **Ad hoc** feature selection / no theoretical justification; accruals and equity issuance are embedded and correlated with other anomalies.
  - **Survivorship / Compustat coverage** discussion: missing non-surviving low-F firms would *understate* the reported high-low spread; back-fill coverage bias argued mitigated because ROA needs 3 years of data.
  - **The paper does NOT state** that F-Score fails for non-manufacturing, financial firms, or non-US samples — those caveats are external (see sources 2 & 3). [Marked: paper is US high-BM only.]
- **Engine-relevant notes:** all nine tests are pure accounting and computable from statements the engine already pulls (annual + quarterly) — **yes** for F_ROA (income stmt NI + prior balance-sheet total assets), F_CFO (cash-flow stmt), F_ΔROA (needs 3 fiscal periods), F_ACCRUAL (NI − CFO, same denominator), F_ΔLEVER (balance-sheet long-term debt incl. current portion ÷ avg total assets, YoY), F_ΔLIQUID (current ratio YoY), F_ΔMARGIN (revenue−COGS)/revenue YoY, F_ΔTURN (revenue ÷ beginning total assets YoY). **Caveats:** (a) beginning-of-year total assets requires the prior period's ending value (engine has it once ≥2 periods available); (b) "income before extraordinary items" is often not exposed separately by yfinance and is rare in modern FMP statements — approximate with net income; (c) F_EQ_OFFER needs year-over-year **shares-outstanding** history (FMP cash-flow `commonStockIssued`/`netCommonStockIssuance` or shares history); buybacks/stock-comp distort a naive share-count delta. Nothing in F-Score uses the engine's OHLCV (beyond return benchmarking), options IV, news/relevance, analyst ratings/targets, prediction markets or FRED — those are orthogonal inputs if the engine wants an independent signal. No sector-neutralisation is native; must be added for cross-sector comparability.

### Source 2: Piotroski F-score — https://en.wikipedia.org/wiki/Piotroski_F-score
- **Status**: retrieved (full wikitext).
- **Variant definitions:** lists the same 9 criteria in the same 3 groups; **accruals criterion stated in ratio form**: "Operating Cash Flow/Total Assets is higher than ROA/Total Assets" (equivalent to F_ACCRUAL=1 iff CFO>ROA). Change-in-shares criterion = "1 point if no new shares were issued during the last year."
- **Bands:** 9 max, 0 min; **F-score of 8–9 = strong**; **F-score of 0–2 = weak** (note: Wikipedia's weak band 0–2 differs from the paper's low portfolio 0–1).
- **Documented caveats/criticism:** average F-score varies by industry (manufacturing vs finance) → take care comparing firms of different specialisations. **Limits:** only compares one year to the previous → hard to apply in **cyclical sectors** or in periods (e.g. COVID-19 2020) that depress all sectors. Improvements suggested by Alpha Architect (2015) and AAII.
- **Failed/qualified replication evidence:** Schwartz & Hanauer (2024, SSRN 5043197) evaluate the formula for the **US market 1963–2022** and compare it with the Magic Formula, Conservative Formula and Acquirer's Multiple: **all four generate significant raw and risk-adjusted returns, but mainly by providing efficient exposure to well-established style factors; no single formula consistently outperforms across all performance metrics.**
- **Engine-relevant notes:** standard public band convention (strong 8–9 / weak 0–2); flags sector dependence and macro-regime sensitivity; the 2024 US replication finds F-Score alpha is largely style-factor exposure rather than unique skill.

### Source 3: Man+Machine – The evolution of fundamental scoring models and ML implications (Carlos Salas Najera, CFA UK) — https://www.cfauk.org/pi-listing/man-machine-the-evolution-of-fundamental-scoring-models-and-ml-implications
- **Status**: retrieved.
- **Evolution of composite fundamental scores (facts stated):**
  - **Altman Z-Score (1968)**: ~94% accuracy one year before bankruptcy, low Type II error; weaknesses listed as dependent-variable dichotomy, sampling method, lack of stationarity, feature-selection bias, geographic/sector bias. Graham Secker applied Z-Score to European stocks: **red zone Z<1 underperformed market by 5–6% p.a., >70% accuracy, 1990–2008**.
  - **Sloan Ratio (1996)**: long low-accrual / short high-accrual = **+10.4% CAGR, 78.9% hit ratio, 1962–1991**; practitioner bands: safe zone −10%..+10%, "bad accounting" >+25% or <−25%, especially if consistent across quarters/years.
  - Xie (2001) discretionary accruals; Hirshleifer-Hou-Teoh-Zhang (2004) NOA scaled by beginning total assets, ideal 2-year accrual window (1964–2002).
  - **Beneish M-Score (1999)**: trained US 1982–1988, tested 1989–1992; **accuracy 76%, Type I 17.5%**, recommended threshold **−1.89**; controls for industry; **recommended only for manufacturing stocks**; later Beneish 2013 found high-probability manipulators underperform ~<1%/month risk-adjusted.
  - **Dechow F-Score (Fraud, 2011)**: SEC-accused firms 1982–2005, **7 indicators / 5 areas**; does **not** control industry/size; high false-positive (Type I) rate; only detects SEC-prosecuted misstatements.
  - **SEC AQM**: discretionary accruals, direct vs indirect factors, aims to minimise false positives.
  - **Piotroski F-Score**: 9 binary signals, profitability (4), liquidity (3), operating efficiency (2). Long portfolio **F=8 or 9**, short **F=1 or 2** [CFA-UK stated variant of the paper's 0–1]. Result: **23.5% CAGR US 1976–1996, +7.5%/yr over a P/B value strategy**. International: **Galdi & Lopes (2009) Brazil +26.7% CAGR; Noma (2010) Japan +17.6% CAGR**.
  - **Mohanram G-Score (2005)**: growth-stock analogue (earnings stability, growth metrics, R&D/capex/advertising intensity); introduces **relative-to-industry-peer comparison**; long/short double-digit excess return, significant alpha after momentum/value/accruals/size; positive 21 of 23 years → **hit ratio >91%**.
  - **Amor-Tapia & Tascon (2016)**: across four European markets, only **G-Score and F-Score survived out-of-sample backtesting with statistically significant alpha** (later models rejected).
- **Weight calibration / aggregation:** the classical scores use **fixed, equal or hand-set coefficients** (F-Score: nine unit-weight binary signals; M-Score: trained logistic coefficients with a −1.89 cut-off; G-Score: fixed relative-to-industry metrics) — no dynamic recalibration. The ML upgrade (below) replaces the fixed additive weighting with learned weights.
- **ML implications / warning about replacing a transparent additive score with ML:** Balachandran, Saraph & Ang (2013, Stanford CS229) enhance a Piotroski long-only strategy on US data **1977–2010**: features = **real-valued (non-binarised) versions of the nine F-score variables**, plus a second set with extra fundamental variables; models = linear regression, logistic classification, SVM; **two-year rolling-window training** (also tested 1, 3, 4 years); dependent variable = next-year return (linear) or binary top-decile membership (logistic/SVM); test-year portfolio = **top decile by predicted probability**. Findings: ML strategies show **higher mean returns but higher standard deviations** than vanilla F-Score; **87.5% of ML strategies beat the F-Score Sharpe ratio**; SVM best risk-adjusted; **no value added** from the additional non-F-Score variables (authors give no detail on them).
  - **Warnings/criticisms of F-Score and of ML replacement:** ratio selection has no robust methodology → selection and human-behavioural bias; F-Score improves a value strategy but delivers **negative alpha once size/quality/momentum risk premia are accounted for** (Piotroski & So 2012; Ng 2009); fat tails and large drawdowns → only for very long-horizon investors with no career risk; its **naive binary design disregards more nuanced ML models**; broader model criticisms: small-sample properties, selection bias, data mining/snooping, poor robustness, faulty indicator design, lack of out-of-sample verification. **McLean & Pontiff (2016) alpha decay: portfolio returns 26% lower out-of-sample and 58% lower post-publication.** The article's stance is pro-ML overall but insists ML must be built on sound fundamental feature design, must guard against overfitting/generalisation error and imbalanced classification, and that humans remain valuable at "exceptions to the rule"/inflection points.
- **Engine-relevant notes:** (a) F-Score's fixed equal weights are a feature (transparency, no fitting) but a documented weakness once other risk premia are controlled; if the engine replaces the additive score with a learned model it should keep the nine real-valued signals as interpretable features and validate out-of-sample (rolling window) against the additive baseline Sharpe. (b) Alpha-decay magnitudes (26%/58%) are a calibration prior for expected post-publication degradation. (c) Sector/industry-relative comparison (Mohanram) is the documented fix for sector-neutrality the base F-Score lacks. (d) Inputs the engine lacks for exact replication of comparison scores: SEC AAER data (Dechow F), full XBRL disclosure deltas (SEC AQM), detailed R&D/advertising intensity for G-Score (often unavailable in yfinance/FMP).
